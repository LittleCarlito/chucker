# Gameplay
## Core
- Tile based
- Course
	- Start course
		- Create first tee box
			- Must extend from base clubhouse
			- Pathways can connect clubhouse and first tee box
		- Create fairway
			- Different fairway speeds
			- Add rough
				- Different thicknesses
			- Add bunkers
			- Add pot bunkers
			- Add refuse areas
			- Add waste areas
			- Add rocks areas
			- Add trees
			- Add streams
				- Different from water tiles
			- Add swamps
				- Different from water tiles
		- Create green
			- Same types of options as above
			- Different green speeds
		- Create second tee box
			- Connect with cart path if necessary
		- Repeat as many times as you want
			- No rules on how many/few holes needed
	- Hole length determines par
	- Player average determines courses par
- Finance
	- Start campaign with X amount
		- Land for first course costs random amount between x - y
	- Every action has assoicated costs
		- Refunds are never full
	- Can go into debt
		- Unable to expand/buy new things but not game over
		- Hitting -X results in game over
	- Loans available
	- Sponorship events available
		- Chance to result in failure and resulting fame/financial loses
- Balance
	- Different building and course types become unlocked as progress is made
		- These get in the way of each other a direction for the course is forced
		- Either become tourist hotspot or champions tournament course
	- Multiple maps must be beat to finish campaign
		- To unlock each map certain types of each courses must be owned/completed
## Buildings
- Clubhouse always starting building
	- Can start with additional buildings given starting perks
- Buildings provide flat stat bonuses
- Smaller types to be added to the course
	- Ball washer
	- Snack shack
- Bigger types to be added to the grounds in general
	- Hotel
	- Spa
	- Training facility
	- Practice green
	- Houses
		- Negative effect to golfers
		- Passively generate income
		- Positive effect to visitor happiness
		- Different types of houses accentuating different benefits
## Map
- Number of acres determined at start
	- Can expand as you go
- Elevation is adjustable
- Permantent fixture
	- Some give boons/busts, some just take up room
	- Things like rocks and water towers
- Positive tiles
	- Pretty trees that are rare and give boons
	- Can be removed and don't come back
- Negative tiles
	- Rocks/refuse that can't have buildings built on them
		- Can be incorporated into course giving them use
	- Desert that can't be used for anything
- Water tiles
	- Not modifiable
	- Some provide scenery bonuses
	- Can be incorporated into the course
